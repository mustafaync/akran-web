```typescript
// File: src/lib/language-context.tsx
const translations = {
  en: {
    hero: {
      title: 'AKRAN',  // Change here
      subtitle: 'Smart and easy appointments...'  // Or here
    }
  }
}
```

### Change Colors (30 seconds)
```typescript
// File: tailwind.config.ts
colors: {
  akran: {
    500: '#22c55e',  // Change this to any color
    600: '#16a34a'
  }
}
```
